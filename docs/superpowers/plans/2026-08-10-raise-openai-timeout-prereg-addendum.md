## 补遗 1：Wilson 95% 的口径（生效）

**结论：标准 Wilson score interval，双侧 95%，`z = 1.959963984540054`，
明确 _不_ 做连续性校正（continuity correction）。`1.96` 这个近似值**不可**使用，理由见下。

### 依据不是约定，是从已冻结的基线反推

原预登记把基线区间写死为 `66/136 = 48.5%`、`Wilson95 [40.3%, 56.9%]`。
**能重现这两个端点的口径才是当初实际用的那一个。** 实测（`/usr/local/bin/node`，2026-08-10）：

| 口径 | `66/136` 的区间 | 与预登记写死的 `[40.3%, 56.9%]` |
|---|---|---|
| **Wilson，无连续性校正，z=1.96** | **40.3% , 56.9%** | ✅ **重现** |
| Wilson，无 CC，z=1.959963985 | 40.3% , 56.9% | ✅ 重现（与 1.96 在一位小数上不可分） |
| Wilson，**带**连续性校正，z=1.96 | 39.9% , 57.2% | ❌ **排除** |
| Wald，z=1.96 | 40.1% , 56.9% | ❌ 排除 |
| Agresti–Coull，z=1.96 | 40.3% , 56.9% | ⚠️ 数值上不可分，**但预登记明写 "Wilson"** ⇒ 按名字排除 |
| Wilson，z=2.0 | 40.1% , 57.0% | ❌ 排除 |
| Wilson，z=1.645（90%） | 41.6% , 55.5% | ❌ 排除 |

⇒ **口径唯一确定。** 但 `z` 的具体取值仍须钉死到一个数：

> 🔴 **`z = 1.959963984540054`（精确值）。不许用 `1.96`，不许现算，不许依赖某个库的默认值。**

**理由是实测的，不是洁癖 —— 我先写了"两者任选"，被数据打脸后改的：**
遍历 `n = 150..400` 的全部 `k`，两个 `z` 的区间端点最大差异仅 `1.5e-4` pp（数值上完全无关紧要），
**但有 146 处真值恰好落在 `x.x50` 的舍入边界上，一位小数的显示会翻**
（例：`k=41, n=152` 下界 `20.549961%` vs `20.550067%` ⇒ 显示 `20.5%` vs `20.6%`）。
主要结局是**拿一个数去卡 40.3% 这个阈值**，所以"只差 1.5e-4 pp"不等于"不影响裁决"。

### 阈值比较必须在未舍入的值上做（这条同样是防自由度）

原文的主要结局写作 **"Wilson95 上界 < 40.3%"**，括号里又说 **"即低于基线区间的下界"**。
这两个说法差 **0.0139pp**：基线下界的未舍入值是 **`0.4028624…`（40.2862%）**，而 `40.3%` 是它的一位小数显示。
⇒ **存在一个宽 0.0139pp 的口径分歧带**（新窗口上界落在 `40.2862% – 40.3%` 之间时，两种读法给出相反结论）。

**读数规则（不引入任何自由度）：**

1. 上界一律报到**小数点后 4 位**（如 `40.2862%`），**不要用舍入后的显示值做比较**。
2. 同时对 `40.3%`（原文字面）与 `0.4028624…`（原文括号里的"基线下界"）各比一次。
3. **两者一致 ⇒ 按一致结论判。两者不一致 ⇒ 判定"不可判定，需人类裁决"，不许自己挑一个。**

这条规则**不替人类选阈值** —— 它只保证：当且仅当两种读法给出相同答案时才允许下结论。
分歧带宽 0.0139pp，而 `n=150` 时区间半宽约 ±8pp ⇒ **它几乎不可能真的绑定**，
但把它写下来的成本是零，而临场发现它的成本是一次事后裁量。

### 公式（读数脚本必须照此实现，不许换等价变形以外的东西）

设 `k` 为事件数、`n` 为分母、`p = k/n`：

```
d      = 1 + z²/n
center = (p + z²/(2n)) / d
half   = z * sqrt( p(1-p)/n + z²/(4n²) ) / d
CI     = [center - half, center + half]
```

**自检（读数脚本跑之前必须先过这一条）：** 输入 `k=66, n=136, z=1.959963984540054`，必须输出

```
lo = 0.4028624249   (40.2862%)
hi = 0.5685337545   (56.8534%)
```

一位小数即 `40.3% / 56.9%`，与原预登记写死的基线区间一致。**对不上就是实现错了，不许继续读数。**
（`0.4028624…` 就是上面"阈值比较"里那个"基线下界的未舍入值"，两处必须用同一个数。）

### 为什么这值得单独钉，而不是"z 就是 1.96，还用说？"

**因为变体会改变裁决方向。** 连续性校正版在同一数据上把上界抬高约 **0.3pp**
（`56.9% → 57.2%`），作用在新窗口上就是**更难**达成"上界 < 40.3%"这个主要结局。
主要结局是一个**卡在阈值上的二元判定**，任何系统性移动上界的自由度都可能翻转结论。
⇒ 这不是精度问题，是自由度问题。

### 为什么这算"补全"而不是"修订"

1. 它**没有新增、删除或放松任何判据**：主要结局仍是"上界 < 40.3%"，n 门槛仍是 150/300，中止判据不变。
2. 它在原文已写的 `Wilson 95%` **内部**消除歧义，且选的是**唯一能重现原文自己写死的基线端点**的那一个 ——
   换句话说，它是在把原文的隐含选择写出来，不是替原文做新选择。
3. 它在**看到结局之前**落定。

⚠️ 若将来发现基线那两个端点其实是用别的口径算出来的（例如某个库的默认带 CC），
**那时的正确动作是再开一份补遗作废本条，不是回来改这里**（Ⅴ："撤回一个说法时，要去原话所在的位置作废它"）。

  `additionalContext` **按设计恒为 `''`**。
- ⇒ **照字面读，判据 3 在窗口第一条数据上就 100% 命中，要求立刻回退一个比本分支早约两个月的常态。**
