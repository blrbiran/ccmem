# ccmem —— 接手入口（10 行）

> 全文在 `docs/handoff/handoff.md`。本页只负责让你**不在前十分钟里做错事**。
> 本页不写 commit SHA、不假设 HEAD 在哪 —— 提交它本身就会移动 HEAD。

1. **先跑 `git status` + `git log --oneline -15`。** 硬禁令：**不要 push**；**删分支/worktree 先问**；**plist 与配置内容不打印、不落盘**。
2. **没有待修的产品 bug。** 未修的是**两条测试抖动**：`admin-daemon-command`（~11%，多模态）、`plist-drift`（~1%）。见 handoff Ⅹ。
3. **⚠️ 套件不是稳定绿：112 次全量跑里 16% 会红。** 看到红**先去 Ⅹ 对号入座**，别当成自己引入的回归。
4. **要动那两条抖动，先读 Ⅹ 再动手** —— 仪器写法、正面对照、一锤定音的判据、需要的跑数都在里面，**别重新设计**。
5. **验证间歇性修复必须用确定性变异判据**（修复前该变异逼出红、修复后同一变异全绿），**不许用"跑 N 次全绿"**。
6. **变异实验必须复现目标的真实条件。** 上一轮两次"单跑变异 0/N"都因缺少全量跑的并发维度而**无效**，差点得出错误的排除结论。
7. **探针：n=58 / 目标 ~300，不要改探针代码；`openai_timeout_ms` 要改先出计划。** 数字**每轮重算**，别照抄任何版本。
8. **🔴 取数前先比对采样窗口与你自己的重活时段。** 上一轮跑测试把探针 `P(ms≤800)` 从 84.5% 压到 50%，差点读成"信号变强"。
9. **人类裁决（handoff Ⅵ）不得静默推翻**，其中 Ⅵ.10：**SDD workspace 一律不删** —— SDD skill 最后一步会让你删，**别听它的**。
10. **成本会失控**：上一轮 ~$127，几乎全花在重复跑套件上。**开工前 `/compact`；要取证就一次跑够 32–48 次**，别 8 次一批反复试。
